Uncover Your True Self: A System for Discovering Personalities and Recommending Videos

Project Summary

This project is a web application designed to help users discover their personality, receive personalized video recommendations, and book consultations with professionals. The system is built with a robust backend, a user-friendly interface, and incorporates AI face recognition for authentication.
